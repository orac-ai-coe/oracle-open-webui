Source: [Oracle font stylesheet](https://static.oracle.com/cdn/fnd/gallery/2104.4.0/OracleFont/OracleFont.min.css).
The unmodified WOFF2 files are from its `OracleSans_Web/WOFF2/` directory.

The global stylesheet serves these assets locally. Weight 500 uses the regular
face, matching Oracle's stylesheet; 600 uses semibold and 700 uses bold.
